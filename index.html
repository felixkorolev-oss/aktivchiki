Управление данными

Как синхронизировать данные между устройствами:

  1. На первом устройстве нажмите "Синхронизировать" - данные сохранятся в облако
  2. На втором устройстве нажмите "Загрузить из облака" - данные появятся
  3. При изменении данных на любом устройстве, нажмите "Синхронизировать" снова

Если облако не настроено, данные сохраняются только локально в браузере. Чтобы перенести данные на другое устройство, используйте "Сохранить в файл" и "Загрузить из файла".
